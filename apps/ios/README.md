# CodeIt for iOS

The website, bundled into a native shell with Capacitor. One codebase: the
React app in `packages/gamified-elearning` is built with the production API
address and copied into the Xcode project here. Nothing in this folder is part
of the root npm workspace, so the website's Vercel build never sees it.

## Run it in the iOS Simulator (free, no Apple Developer Program needed)

On the Mac, once:

1. Install Xcode from the Mac App Store (free), open it once and accept the licence.
2. `cd ~/CodeIt/apps/ios && npm install`

Then, every time:

```
cd ~/CodeIt/apps/ios && npm run app
```

That builds the website for the app (`build:web`), copies it into the Xcode
project (`sync`), and opens Xcode (`open`). In Xcode pick an iPhone simulator
at the top and press Run.

## What the shell does and does not do yet

- Serves the whole site from inside the app at `capacitor://localhost`; API
  calls go to https://codeitlearn.com, which allows that origin.
- Python lessons run in the app (Pyodide loads from its CDN, so the app needs
  the internet, as the site does).
- No in-app purchase yet: Plus is sold on the website. Before an App Store
  submission the Plus subscription inside the app must move to Apple's in-app
  purchase, and the app needs the native pieces App Review looks for
  (guideline 4.2): offline lessons, notifications, native sharing.
- Installing on a real iPhone (TestFlight) and submitting both need the Apple
  Developer Program, 99 USD a year, which is the owner's decision and account.

`ios/App/App/public` and the copied `capacitor.config.json` are generated by
`sync` and are not committed.
