Make a website. Learn the code behind it.

CodeIt helps kids and beginner coders create websites, games, and quizzes, inspect the code behind them, and keep improving every project.

What families can do today

  • Students ages 8 to 14 can build, edit, save, and learn from real browser projects.
  • Parents can create a private managed learner profile for a child under 13, which CodeIt supports from age 5, and receive progress updates.
  • Families can request a free pilot spot. No card or paid subscription starts automatically.
