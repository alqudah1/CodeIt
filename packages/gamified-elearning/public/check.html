Does CodeIt work on this computer?

This page tries everything CodeIt needs, from this computer, on this network. It takes about half a minute.

Checking…

    For whoever looks after the network

    CodeIt needs one address and nothing else: https://codeitlearn.com. Every page, script, font and picture comes from it, and so does Python (under /pyodide/).

    If a line above is red, the filter is letting the page through but stopping a file the page needs. Allowing codeitlearn.com for all file types, including scripts and .wasm, fixes it. On a filter that reads what is inside each file, that means leaving this one address out of that reading as well.

    The copied results name every file that was stopped, how big it is, and what the network sent back in its place.
