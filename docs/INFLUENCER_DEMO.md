# CodeIt influencer walkthrough

## What CodeIt is

CodeIt helps students turn an idea into a real website, game, or quiz, then
learn, edit, save, and share the code behind what they built.

The key difference is simple: students do not begin with an intimidating blank
editor. They begin with something they genuinely want to create, then CodeIt
connects the result to the coding concepts that make it work.

## The three-minute walkthrough

### 1. Start on the homepage

Say:

> A student starts with an idea, not a blank screen. CodeIt helps them make a
> real project and then understand the code behind it.

Point out the three promises shown immediately:

- Students create.
- CodeIt teaches.
- Parents see progress.

### 2. Open the project builder

Choose the space quiz example, or enter:

> Build a colourful space quiz with three questions, a score counter, and
> confetti when I finish.

Explain:

> The first version removes the scary first step. It is a starting point, not
> the end of the learning.

### 3. Connect the project to learning

Show that the student can preview the result, change it, inspect the code, and
open a related lesson.

Say:

> General AI builders stop after making something. CodeIt turns the project
> into a reason to learn variables, events, conditions, loops, and design.

### 4. Show parent value

Return to the homepage and scroll to the parent progress example.

Say:

> With parent-approved updates, a parent can see meaningful milestones such as
> a completed lesson, a created project, or a published website.

### 5. Finish with one action

Say:

> The action we want from a student is: build a free project. The action we
> want from a parent is: join the Founding Family waitlist.

## What to promote

The strongest content is a short screen recording that shows the finished
result first, then how it was made.

Use one of these hooks:

- “I asked CodeIt to build a space quiz.”
- “A student idea became a real website.”
- “This game teaches the code behind the score.”
- “Parents can finally see what their child built.”

Keep most videos between 15 and 35 seconds, add captions, and use only one call
to action: **Build a free project.**

## Important accuracy notes

- The Founding Family plan is a proposed US$12/month pilot; billing is not live.
- Present parent updates as parent-approved.
- Do not claim guaranteed learning, grades, or career outcomes.
- Do not use a student's name, face, project, or personal information without
  the appropriate permission.
